DistributionMetrics

Metrics for measuring how well an approximate probability distribution matches a reference distribution, either from samples or from (possibly unnormalized) log-densities.

All metrics are evaluated by calculate_metric (lower is better). Samples are matrices with one sample per column.

Metric types

DistributionMetrics.DistributionMetric — Type

Subtypes of DistributionMetric evaluate the quality of an approximate distribution with respect to a reference (true) distribution.

The metrics are grouped into two categories; SampleMetric and PDFMetric.

source
DistributionMetrics.SampleMetric — Type

A DistributionMetric computed from samples of the true and the approximate distribution.

Each subtype should implement:

  • calculate_metric(::SampleMetric, true_samples::AbstractMatrix{<:Real}, approx_samples::AbstractMatrix{<:Real}; info=false) -> ::Real
source
DistributionMetrics.PDFMetric — Type

A DistributionMetric computed from the (possibly unnormalized) log-densities of the true and the approximate distribution.

Each subtype should implement:

  • calculate_metric(::PDFMetric, true_logpdf::Function, approx_logpdf::Function; info=false) -> ::Real
source
DistributionMetrics.calculate_metric — Function
score = calculate_metric(::SampleMetric, true_samples, approx_samples; info=false)
score = calculate_metric(::PDFMetric, true_logpdf, approx_logpdf; info=false)

Evaluate the accuracy of the approximate distribution. Lower scores are better.

Samples are matrices with one sample per column. Log-densities are functions mapping a vector to a real number.

Keywords

  • info::Bool=false: Print progress messages.

Total Variation

DistributionMetrics.TVMetric — Type
TVMetric(; grid, ws | log_ws, true_logpost | true_logvals)

Approximates the Total Variation (TV) distance between the true and the approximate distribution by a weighted sum over a precomputed grid of points.

Keywords

  • grid::Matrix{Float64}: The points used to approximate the TV integral (one point per column).
  • log_ws::Vector{Float64}: The log-weights of the grid points. Should be -log q(x), where q is the density used to sample the grid (-log(area) is appropriate for an evenly distributed grid). The non-logarithmic weights ws can be given instead.
  • true_logpost::Function: The (possibly unnormalized) true log-density. If given, its values on the grid are computed once and cached.
  • true_logvals::Vector{Float64}: The (possibly unnormalized) true log-density values on the grid. Used directly if the values are precomputed or can be computed more efficiently in a batch.

Maximum Mean Discrepancy

DistributionMetrics.MMDMetric — Type
MMDMetric(; kernel)

Approximates the Maximum Mean Discrepancy (MMD) between samples of the true and the approximate distribution.

Keywords

  • kernel::Kernel: The kernel used to calculate the MMD. The kernel lengthscales have to be chosen appropriately (see OptMMDMetric for automatic tuning).
source
DistributionMetrics.OptMMDMetric — Type
OptMMDMetric(; kernel, bounds, algorithm, kwargs...)

Like MMDMetric, but the kernel lengthscales are optimized to maximize the MMD during each evaluation of the metric.

Keywords

  • kernel::Kernel: The kernel without lengthscales.
  • bounds: Tuple (lb, ub) of the bounds of the sampled domain.
  • algorithm: The optimization algorithm (an Optimization.jl solver) used to optimize the lengthscales.
  • kwargs...: Passed to the optimization algorithm.
